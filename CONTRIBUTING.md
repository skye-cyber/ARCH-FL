## Non-collaborator
- [ ] **If you are not a collaborator:**
> - Fork this repo first
    ```
    1. Click 'Fork' at top-right of repository page
    2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/FLEMSIM.git`
    3. Add upstream: `git remote add upstream https://github.com/skye-cyber/FLEMSIM.git`
    ```

## Collaborator
- [ ] For collaborators:
> - Create your new work branch
    ```
    git checkout -b feat/your-feature-name  # for features
    git checkout -b fix/your-bug-fix       # for bug fixes
    git checkout -b docs/your-update       # for documentation
    ```

## General
- [ ] All commits must be signed
    ```
    git commit -S -m "Your commit message"  # -S flag enables signing
    ```

- To merge to main, all conflicts from source branch must be resolved

- Minimum permissions are employed. For permission issues, contact [swskye17@gmail.com](mailto:swskye17@gmail.com). For other issues, create one [here](https://github.com/skye-cyber/ARCH-FL/issues).
